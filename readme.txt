# チェスVS将棋 夢の対決!

## 概要

チェスと将棋で戦えます　まだβ版なのでかなりのルールが実装されてないけど動きはします

## ルール

・ボードの大きさはタテ9xヨコ8 (将棋側は6三金と6一歩が持ち駒に移動予定)
・キャスリング等チェス固有ルールはチェス側のみ、持ち駒は初期のそれ以外なし
・千日手は王手を除いて三回で引き分け、ステイルメイトもあり
・その他条件はチェス、将棋側どちらも同じ
・ゲームバランスはてきとう　就職と修飾はがんばらない
